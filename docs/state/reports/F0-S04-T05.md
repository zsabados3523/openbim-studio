# F0-S04-T05: sonda da thread de desenho

Janela Qt nativa (`QWindow`) desenhada com QRhi por uma thread do C++ (limpa a tela mudando de cor, registra o instante de cada quadro apresentado, 60 quadros/s pedidos), embutida por contêiner de janela numa janela PySide6. Nenhum método da janela é sobrescrito em Python; a thread nunca chama Python. Fonte em `prototypes/s04/sonda_desenho/` (CMake, `sonda_desenho.cpp`, `sonda.py`). Qt 6.11.2 do ambiente travado, ligado por `Qt6::GuiPrivate` (liga sem problema).

## Linux (tela virtual `xvfb-run`, OpenGL por software Mesa llvmpipe), duas rodadas
Meta: maior intervalo entre quadros < 50 ms.

| Fase | Quadros/s | Maior intervalo (rodada 1 / 2) |
|---|---|---|
| A. parado (2 s) | 62,5 | 17,8 / 16,5 ms |
| B. lote `ifcopenshell.api` em thread Python (4 s, ~14 mil operações) | 62,4 | 17,4 / 16,2 ms |
| C. chamada C de 0,75 s (3x) em thread Python | 62,4 | 16,8 / 16,6 ms |
| D. chamada C de 0,75 s (3x) na própria thread principal (janela PySide6 parada) | 62,5 | 16,7 / 17,4 ms |

- Mediana de todos os intervalos: 16,0 ms. Maior intervalo durante o lote ≈ o parado (razão ~1; critério do lote 9: ≤ 3x).
- Comparação com o F9 (componente na thread da janela): 467 a 990 ms de parada. Com a thread própria: 17 ms.
- 20 ciclos de redimensionar, esconder e mostrar: 0 falhas (a thread voltou a desenhar depois de cada "mostrar"; a swapchain é solta na thread de desenho quando a superfície vai sumir).
- 20 aberturas e fechamentos (criar, mostrar, desenhar, fechar; fechamento espera a thread terminar): 0 quedas, 0 janelas sem quadros.
- **Meta atingida no Linux.** Rodar: `xvfb-run -a env QT_QPA_PLATFORM=xcb LIBGL_ALWAYS_SOFTWARE=1 python sonda.py <pasta-do-módulo> <saida.json>`.

## Windows (D3D11 por software/WARP)
Passo informativo no `ci.yml` (jobs `linux` e `windows`, `continue-on-error`). O CI só dispara em PR para o `main`; sem PR, o número do Windows **ainda não existe**. O código do ramo D3D11 não foi compilado nem rodado (só o Linux foi).

## Limites da sonda
Desenho por software e janela pequena: o número prova a independência do Python, não a placa. Os quadros são pacejados a 16 ms (sleep), então o intervalo ideal é 16 ms; o que importa é o maior intervalo. Não mede resposta ao mouse (M5b).
