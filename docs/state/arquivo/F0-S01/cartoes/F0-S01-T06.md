Para cada componente do grupo, uma ficha curta confirmando a licença na **fonte primária** e dizendo se pode ser usado no OpenBIM Studio (AGPL v3) e com que condições. Componentes: IfcOpenShell (núcleo C++), ifcopenshell-python, Open CASCADE (OCCT), pythonocc-core.

## Critérios de aceite
1. Uma linha por componente: licença em SPDX, versão ou tag consultada, URL do LICENSE, data de acesso, "compatível com AGPL v3: sim/não/condição", condições (atribuição, relink, exceções).
2. OCCT: registrar com todas as letras "LGPL-2.1-**only** + Open CASCADE Exception 1.0" e deixar a pergunta "linkar com AGPL v3 é compatível?" marcada para o opus (a tabela de 05 §3 só cobre "2.1+/3").
3. Itens marcados "Parcial" ou "Não verificado" em `v2/07` reconfirmados ou mantidos como "não verificado" com o motivo.
4. Nenhum texto de licença colado além de uma citação curta do nome e da cláusula, e nenhum trecho de norma ABNT.
