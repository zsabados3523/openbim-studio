## 5. Premissas refutadas ou corrigidas (resumo)
1. **"O Bonsai guarda tudo no IFC"**: falso para o layout de pranchas (fica no SVG) e estilos (CSS). Apoia a Opção 2.
2. **Qt RHI como API pública estável**: é semi-pública; novo risco R13.
3. **"conda-forge tem tudo nos 3 sistemas"**: OCCT no conda-forge não confirmado; validar antes do ADR-005.
4. **IFC4 como formato de troca**: para ArchiCAD↔Revit o padrão certificado ainda é IFC2x3 CV 2.0; exportação 2x3 sobe de prioridade.
5. **SINAPI redistribuível com atribuição**: sem termos encontrados; passa a "importar arquivo do usuário" apenas.
6. **libdxfrw**: possível GPLv2-only (incompatível); não usar sem checagem.
7. **Soma do calendário anterior**: as faixas por fase somavam 68–136 semanas (≈ 15,7–31,4 meses), não 18–36; ver `02` §14.
