# Relatório da fatia F0-S02 (CI e app esqueleto)

Em 10 linhas, para o PO. Roteiro de aceite: `docs/acceptance/F0-S02.md`.
1. **O que está provado:** o programa esqueleto abre e mostra o resumo de um IFC no Windows e no Linux, e o CI roda os mesmos testes nos dois (e no macOS, sem bloquear).
2. **CI verde:** Linux 66 s, macOS 93 s, Windows 939 s (execução 38110728020: https://github.com/zsabados3523/openbim-studio/actions/runs/38110728020).
3. **Instalador Windows:** 482 MB (meta 600 MB). Instala sem senha de administrador, abre e desinstala sem sobras, testado automaticamente.
4. **Pacote Linux (AppImage):** 390 MB (meta 600 MB), mas montado só na máquina do líder; falta o CI gerá-lo (precisa do seu ok para baixar a ferramenta).
5. **Licenças:** achamos que o pacote levava um tocador de vídeo GPL (ffmpeg) que não usamos; foi removido dos dois pacotes. O inventário e o REUSE passam.
6. **Bloqueio de merge:** ativo; nada entra no `main` sem Linux e Windows verdes (fluxo por ramo e pull request).
7. **Build incremental:** não medido (sem cache no CI); proposta no relatório de métricas.
8. **Gravação de vídeo sem tela:** o plano B (capturas e GIF animado) funciona no Linux; Windows a confirmar no próximo CI.
9. **Falta para fechar a S02:** seu teste do roteiro (parte A), ok para o AppImage no CI, revisão obrigatória do Opus (lote 2: AppImage, instalador, tabela de licenças) e o ADR-005 final.
10. **Riscos:** o Windows leva ~16 min por execução; o instalador não é assinado (aviso do SmartScreen).
