# viewport

Viewport 3D em Python.

- `viewport_qrhi/`: viewport com `QRhiWidget`, câmera, seleção por clique e abertura de IFC em processo auxiliar. Ver o `README.md` da pasta.
- `formato_malha.py`: formato dos vértices e dos objetos, igual ao do `native/obimcore/`; `tests/test_formato_malha.py` confere os dois lados.

Para importar, ponha `viewport/` no caminho do Python (`import viewport_qrhi`, `import formato_malha`). Os testes ficam em `tests/`.
