# F0-S04-T05: sonda da thread de desenho

Janela Qt nativa (`QWindow`) desenhada com QRhi por uma thread do C++ (limpa a tela mudando de cor, registra o instante de cada quadro apresentado, 60 quadros/s pedidos), embutida por contêiner de janela numa janela PySide6. Nenhum método da janela é sobrescrito em Python; a thread nunca chama Python. Fonte em `prototypes/s04/sonda_desenho/` (CMake, `sonda_desenho.cpp`, `sonda.py`). Qt 6.11.2 do ambiente travado, ligado por `Qt6::GuiPrivate` (liga sem problema).

- Comparação com o F9 (componente na thread da janela): 467 a 990 ms de parada. Com a thread própria: 17 ms.

- **Meta atingida no Linux.** Rodar: `xvfb-run -a env QT_QPA_PLATFORM=xcb LIBGL_ALWAYS_SOFTWARE=1 python sonda.py <pasta-do-módulo> <saida.json>`.

## Limites da sonda
Desenho por software e janela pequena: o número prova a independência do Python, não a placa. Os quadros são pacejados a 16 ms (sleep), então o intervalo ideal é 16 ms; o que importa é o maior intervalo. Não mede resposta ao mouse (M5b).
