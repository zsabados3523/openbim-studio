# F0-S03-T06: Seleção por clique
- Classe: T2 · Implementa: sonnet (subagente) · Revisa: sonnet; amostra opus no lote 4 · Oráculo: testes de seleção sem tela (raio × triângulos) e, com tela, clique simulado seleciona o objeto esperado; tempo medido no modelo de 1 milhão de triângulos
- Depende de: S03-T03, S03-T04 · Tamanho máximo do diff: 400 linhas
## Objetivo
`Viewport.pick(x, y) -> id | None`: lança um raio a partir da câmera (`Camera`) e acha o triângulo mais próximo; devolve o id do objeto dono (cada objeto tem um id; a malha é uma lista de objetos). Implementação em Python com numpy, **sem GPU** (CPU), com uma estrutura simples de aceleração (caixas delimitadoras por objeto e, se preciso, grade) para atingir **< 100 ms** com 1 milhão de triângulos (`corpus/modelo-grande-1m.ifc` gerado por `scripts/gerar_modelo_grande.py`; construir a malha a partir dele por iterador simples, sem threads: threads são da T05). Destaque do objeto selecionado (cor) é opcional.
