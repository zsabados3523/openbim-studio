# Roteiro de aceite da S02: instalar o programa e abrir um IFC

Para você, Rafael. Responda no chat em linguagem natural (ex.: "passos 1 a 9 ok; no 6 apareceu um aviso"). Tempo: uns 15 minutos no Windows.
Dois avisos antes de começar:
- No Windows, o programa **ainda não tem assinatura digital**, então o Windows mostra um aviso azul ("O Windows protegeu o computador"). É esperado até a v0.3.
- O IFC de teste (`casa-simples.ifc`) foi gerado por nós; não é de terceiros.

## Parte A: Windows (máquina virtual ou real)
| # | O que fazer | Resultado esperado | ✅/❌ | Observação |
|---|---|---|---|---|
| 1 | No navegador, abra a página do projeto no GitHub, aba **Actions**, e clique na execução verde mais recente do ramo `main`. | Página com a lista "Artifacts" no fim. | | |
| 2 | Clique em **openbim-ci-windows** para baixar (arquivo ZIP, uns 480 MB). | O download termina. | | |
| 3 | Extraia o ZIP (clique direito > Extrair tudo). | Aparece `OpenBIM-Studio-Setup.exe` (o instalador). | | |
| 4 | Dê dois cliques no instalador. Se aparecer o aviso azul, clique em **Mais informações** e depois **Executar assim mesmo**. | A janela do instalador abre, em português, com a licença AGPL. | | |
| 5 | Clique em **Aceito / Avançar** até **Instalar**. Não precisa de senha de administrador. | Barra de progresso; leva 1 a 3 minutos. | | |
| 6 | Abra o **OpenBIM Studio** pelo atalho na área de trabalho ou pelo menu Iniciar. | Abre uma janela com menus **Arquivo** e **Ajuda** e a mensagem "A viewport 3D entra na fatia S03". | | |
| 7 | Baixe o IFC de teste: abra `github.com/zsabados3523/openbim-studio/raw/main/docs/acceptance/amostras/casa-simples.ifc` e salve o arquivo. | Arquivo `casa-simples.ifc` (4 KB) na pasta Downloads. | | |
| 8 | No programa: **Arquivo > Abrir IFC…** e escolha `casa-simples.ifc` (ou arraste o arquivo para a janela). | No centro aparece o resumo: **IFC4, 8 elementos, IfcWall: 4**, e a barra de baixo repete isso. | | |
| 9 | Arquivo > Abrir IFC… e escolha um arquivo que **não** seja IFC (por exemplo um .txt renomeado para .ifc). | Uma mensagem de erro em português; o programa **não fecha**. | | |
| 10 | Feche o programa e desinstale: menu Iniciar > OpenBIM Studio > **Desinstalar** (ou Configurações > Aplicativos). | Pergunta de confirmação e, depois, o atalho some. | | |
| 11 | Abra a pasta `%LOCALAPPDATA%\Programs` (cole no Explorer). | **Não** existe mais a pasta "OpenBIM Studio". | | |

## Parte B: Linux (Ubuntu ou Fedora)
O pacote Linux (arquivo único com extensão `.AppImage`, que roda sem instalar) **ainda não é gerado pelo CI**; hoje só existe o montado na máquina do líder. Esta parte fica para depois que você autorizar baixar a ferramenta de montagem no CI (pendência registrada no relatório F0-S02-metricas).
| # | O que fazer | Resultado esperado | ✅/❌ | Observação |
|---|---|---|---|---|
| 12 | Baixe `OpenBIM-Studio-x86_64.AppImage`, clique com o botão direito > Propriedades > **Permitir executar como programa**. | A opção fica marcada. | | |
| 13 | Dê dois cliques no arquivo. | Abre a mesma janela do passo 6. | | |
| 14 | Arquivo > Abrir IFC… com `casa-simples.ifc`. | Mesmo resumo do passo 8. | | |
| 15 | Feche o programa. | Fecha sem erro. | | |
