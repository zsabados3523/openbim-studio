# F0-S02-T06: CI Linux (build, teste, artefato, checagem de licenças)
- Classe: T2 · Implementa: sonnet · Revisa: sonnet; amostra de 1 em 3 vai ao opus · Oráculo: execução verde no GitHub Actions, com log
- Depende de: S02-T05, S01-T01 (repositório remoto existente) · Tamanho máximo do diff: 400 linhas
## Objetivo
Um fluxo de CI que, a cada alteração, cria o ambiente, roda os testes sem tela e guarda um artefato. Inclui a checagem automática de licenças e cabeçalhos (REUSE/SPDX), pedida em `v2/05` §3 "a partir da F0".
## Ler antes
- `v2/03` S02 · `v2/02` §12 · `environment.yml` · fichas de licença (D)
## Arquivos permitidos
- `.github/workflows/ci.yml`, `docs/dev-setup.md` (seção CI), `REUSE.toml` ou arquivos de licença que a checagem exigir
## Critérios de aceite
1. Fluxo verde no runner Linux x64; testes e checagem de licença passam.
2. Artefato (pacote do app esqueleto) disponível por link; tempo total registrado.
3. Ações de terceiros fixadas por versão exata; nenhum segredo no fluxo.
## Armadilhas conhecidas
- AUTORIZAÇÃO: o líder só empurra para o GitHub com ok do PO; instalar a ferramenta REUSE pede ok.
- O CI só prova algo depois do push; não declarar sucesso sem o link do log.
- Cache do ambiente pode mascarar tempo de build limpo: medir também sem cache.
