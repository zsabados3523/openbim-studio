# F0-S03-T02: Modelo grande para o benchmark
- Classe: T1 · Implementa: sonnet · Revisa: sonnet · Oráculo: o script gera um IFC válido (abre no IfcOpenShell) com ~1 milhão de triângulos; mesmo resultado a cada execução
- Depende de: S03-T01 · Tamanho máximo do diff: 400 linhas
## Objetivo
Substituir o download de um IFC público (sem licença confirmada, ver ficha) por um gerador `scripts/gerar_modelo_grande.py` que multiplica andares/ambientes a partir de `docs/acceptance/amostras/casa-simples.ifc` (ou usa `scripts/gerar_casa_simples.py`) até o tamanho pedido. Os arquivos gerados ficam em `corpus/` fora do controle de versão (ou em pasta ignorada), nunca no repositório.
## Arquivos permitidos
`scripts/gerar_modelo_grande.py`, `tests/test_gerar_modelo_grande.py`, `corpus/README.md`, `.gitignore`
## Critérios de aceite
1. Parâmetro de quantidade; o IFC abre no `ifcopenshell` e tem a quantidade pedida de elementos. 2. Saída determinística. 3. Teste rápido com tamanho pequeno. 4. Registrar contagem de triângulos real (via iterador de geometria) no README.
## Fora de escopo
Tempo de abrir IFC real de ~100 MB (medido só na máquina do PO).
