## Objetivo
Dar ao projeto um histórico de versões: repositório local, repositório público no GitHub (principal) e espelho no Codeberg. Contas e criação dos repositórios vazios são do PO; o líder explica cada clique em pt-BR e só roda os comandos locais.
## Ler antes
- `v2/03` S01 · `v2/02` §12 "Hospedagem" · `docs/state/PO.md` (P6)
## Arquivos permitidos
- Nenhum arquivo do produto. Só `.git/` local e a configuração do remoto.
## Critérios de aceite
1. PO respondeu P6 no chat (sem isso, parar com `PRECISA_PO`).
2. `git init` com ramo principal `main`; primeiro commit contém só o que já existe (CLAUDE.md, docs/, v2/ e os 3 arquivos do plano antigo, sem alterá-los).
3. PO criou o repositório vazio público no GitHub; o líder conectou o remoto; push feito **somente após o PO dizer "pode"**.
4. Espelho no Codeberg: o PO escolhe o método (cópia automática oferecida pelo Codeberg ou GitHub Actions); registrar em `docs/state/LOG.md`. Se o PO preferir deixar o espelho para depois, registrar e seguir.
## Armadilhas conhecidas
- Nunca pedir nem anotar senha ou token do PO no chat; o PO digita no navegador ou no terminal dele.
- Repositório público: conferir que nada de `docs/` com dados do PO está no primeiro commit (hoje não há).
- Se houver "Co-Authored-By" exigido pelo ambiente, seguir a regra de commit vigente.
