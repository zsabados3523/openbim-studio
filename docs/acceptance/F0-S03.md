# Roteiro de aceite da S03 (parte do desenho 3D): ver o cubo no Windows

Para você, Rafael. Só vale se o CI não provar o desenho no Windows (veja o passo "Desenho do cubo" na execução do CI e o relatório `docs/state/reports/F0-S03-ci-desenho.md`). Tempo: uns 10 minutos, na VM Windows.

| # | O que fazer | Resultado esperado | OK/não | Observação |
|---|---|---|---|---|
| 1 | Na aba **Actions** do GitHub, abra a execução mais recente e veja o aviso "desenho do cubo no Windows" (e o Linux). | Diz DESENHA ou NÃO DESENHA. Se DESENHA, baixe **openbim-ci-windows**, abra `desenho/cubo.png` e confirme que é um cubo colorido; **pare aqui**, o resto é desnecessário. | | |
| 2 | Se NÃO DESENHA: instale o programa pelo roteiro da S02 e abra o OpenBIM Studio. | Programa abre. | | |
| 3 | Abra a viewport 3D (quando a S03 a expuser no app) ou rode o protótipo: `python -m viewport_qrhi` dentro da pasta `prototypes`. | Janela com um cubo colorido. | | |
| 4 | Arraste com o botão esquerdo, role a roda do mouse. | O cubo gira e aproxima/afasta sem travar. | | |
| 5 | Tire uma foto da tela (tecla Windows + Shift + S) e mande no chat. | Imagem do cubo. | | |
