- Classe: T2 · Implementa: sonnet (subagente) · Revisa: sonnet · Oráculo: um teste que desenha um quadro e salva um PNG com o cubo (pixels não uniformes); abre no Linux e, no CI, no Windows

## Objetivo
Em `prototypes/viewport_qrhi/`: um `QRhiWidget` (PySide6 6.11.2) que mostra um cubo colorido girando, com a interface própria `Viewport` (classe abstrata mínima: `set_mesh(vertices, indices)`, `grab_image() -> QImage`) e o desenho de baixo nível isolado num único arquivo. Shaders em GLSL compilados com o `qsb` do ambiente (`~/miniforge3/envs/openbim/lib/qt6/bin/qsb`) e os `.qsb` gerados no repositório com o `.vert/.frag` de origem.

## Critérios de aceite
1. Roda sem erro no Linux (com tela, `DISPLAY` existente) e desenha o cubo; descrever em README como rodar.
2. Teste automático: cria o widget, força 1 quadro, `grabFramebuffer()` salva PNG; confere que a imagem não é de uma cor só. Se o ambiente sem tela (offscreen/CI) não conseguir criar o contexto, o teste deve **pular com mensagem clara** e o relatório dizer isso (nunca passar em falso).
3. Cabeçalho SPDX `AGPL-3.0-or-later` em todo arquivo; `reuse lint` passa (`.qsb` binário: entrada em `REUSE.toml` se preciso, sem inventar licença).
4. Relatório curto: backend escolhido por padrão no Linux (OpenGL?) e se Vulkan funciona via `setApi`.
